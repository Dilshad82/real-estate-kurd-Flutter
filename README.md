# 🏢 Real Estate Kurd (Flutter Application)

تطبيق عقارات حديث متكامل مبني باستخدام **Flutter** لإدارة وعرض العقارات في منطقة كردستان. يتيح للمستخدمين البحث عن العقارات، الاستعراض، وتصفح التفاصيل بسهولة وسلاسة.

---

## 🌟 الميزات الرئيسية (Features)

* 🔍 **بحث وتصفية متقدمة:** إمكانية البحث عن العقارات حسب الموقع، السعر، والنوع (بيع/إيجار).
* 📸 **معرض الصور:** عرض صور العقارات بجودة عالية.
* 📍 **تفاصيل العقار:** عرض كافة التفاصيل والخدمات المتاحة للموقع.
* 📱 **واجهة تجاوبية:** تصميم عصري ومتوافق مع جميع شاشات هواتف Android و iOS.
* 🌐 **دعم الاتصال بـ API:** مهيأ للربط مع خادم خلفي (Laravel Backend).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** [Flutter](https://flutter.dev/) (Dart)
* **Backend API:** Laravel (RESTful API)
* **State Management:** Provider / Bloc
* **HTTP Client:** Http / Dio
